1. Walk the string with an index `i` and three pieces of state: `args` (finished arguments), `current` (a list of characters of the argument being built) and `in_word` (True once an argument has started, even if it is still empty). Use `in_word`, not "is `current` empty?", to decide whether an argument exists, because `''` is a real empty argument and a bare space run is not.
2. Handle one case per loop turn. Unquoted whitespace: if `in_word`, finish the argument. A backslash: if it is the last character raise ValueError, if the next character is a newline skip both without starting an argument, otherwise keep the next character and set `in_word`. A single quote: `line.find("'", i + 1)` finds the end (raise ValueError if it is -1), keep the text between literally. Anything else: add the character and set `in_word`.
3. A double quote needs its own inner loop that runs until the closing quote (raise ValueError if the line ends first, and also if a backslash is the last character). Inside it: a backslash followed by one of `\`, `"`, `$`, backtick keeps only that second character; a backslash followed by a newline is dropped completely; a backslash followed by anything else keeps the backslash and then lets the loop handle the next character normally. When the loop ends, add the last argument if `in_word`.
