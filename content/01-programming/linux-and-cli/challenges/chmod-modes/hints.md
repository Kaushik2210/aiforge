1. Think in masks, not in letters. User bits are 0o700, group 0o070, other 0o007, and the special bits are 0o4000 (setuid), 0o2000 (setgid) and 0o1000 (sticky). Turn each clause into a list of changes, where each change holds the operator, the "affected" mask (0 when WHO is empty, 0o7777 for a), the "value" bits (r means 0o444, w means 0o222, x means 0o111), and then apply the changes one after the other to a running result.
2. For one change, first work out `value`: for a copy letter take the source class's rwx bits from the running result and spread each of r, w and x over all three classes; for X add 0o111 only if `is_dir` or the running result already has an x bit. Then keep only what the change may touch: `value &= affected if affected else ~umask`. After that, `+` is `new |= value`, `-` is `new &= ~value`, and `=` is `new = (new & ~affected) | value` (with an empty WHO, `affected` is 0 so clear everything first). Letters s and t add 0o6000 and 0o1000 to value, and the affected masks u = 0o4700, g = 0o2070, o = 0o1007, a = 0o7777 are what make `o+s` and `u+t` do nothing.
3. Directories: for a clause with `mentioned` bits (for a symbolic clause, `affected & value`, or just `value` if WHO is empty; for octal specs of fewer than five digits, the spec's own setuid and setgid bits plus sticky and rwx), compute `omit = (0o6000 if is_dir else 0) & ~mentioned` and do `value &= ~omit`, and treat `omit` as preserved in `=`. For `mode_string`, build the nine rwx characters first, then overwrite position 3, 6 and 9: lower-case s or t when the x bit under it is set, upper-case S or T when it is not.
