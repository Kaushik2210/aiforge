1. Split the text in two at the first empty line. The part before it is the head (status line plus headers) and the part after it is the raw body. Line endings are CRLF, but accept a bare LF too: a regular expression such as `\r?\n` does both.
2. The status line is `HTTP/1.1 404 Not Found`: a version, a three-digit code, then a reason that may hold spaces or be empty. `line.split(" ", 2)` gives three parts. Check the version starts with `HTTP/` and that the code is exactly three ASCII digits, or raise `ValueError` with a message that quotes the bad line.
3. For each header line, `name, sep, value = line.partition(":")` splits at the FIRST colon only (a `Date` value contains colons). Store the name in lower case and strip spaces and tabs from the value. If the name is already stored, append `", " + value`. A line with no colon is an error. For the body: if `content-length` is present, it must be all digits. Return exactly that many characters. If fewer are there, raise `ValueError` (the response is incomplete). If the header is absent, the body is everything after the empty line.
