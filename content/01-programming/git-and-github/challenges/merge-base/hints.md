1. Write a helper that returns every commit reachable from one start commit, including the start commit itself. Use a `set` called `seen` and a list used as a stack, and loop with `while stack:`. A recursive version will crash on a long history.
2. The common ancestors are `ancestors(a) & ancestors(b)`. If that set is empty, return `None`. Check first that `a` and `b` are keys of the graph and raise `KeyError("unknown commit id: ...")` if not; a parent id missing from the graph is also a `KeyError`.
3. A common commit is not "best" if it is a parent of another common commit, because then it lies below that one (every ancestor of a common commit is also common). Collect all parents of all common commits into a `covered` set, then return `min(common - covered)`. The `min` is the rule for criss-cross merges, where several best ancestors can remain.
