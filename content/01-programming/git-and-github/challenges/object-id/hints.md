1. Check the inputs first, in this order: `kind` must be a `str` (else `TypeError`), then it must be one of `blob`, `tree`, `commit`, `tag` (else `ValueError`), then `data` must be exactly `bytes` (else `TypeError`). A `bytearray` is not accepted.
2. The text that gets hashed is `kind`, a space, the number of BYTES in `data` as decimal digits, a NUL byte (`b"\0"`), then the data. Build it as bytes, hash it with `hashlib.sha1(...)` and return `.hexdigest()`. The empty blob must give `e69de29b...`; if it does not, your header is wrong.
3. For `commit_body`, make a list of lines: `tree <id>`, one `parent <id>` per parent in the given order, `author <author>`, `committer <committer>`. Join them with `"\n"`, add `"\n\n"` and then the message exactly as given (add nothing), and encode as UTF-8. Reject a parents value that is not a list or tuple (`TypeError`), ids that do not match 40 lower-case hex characters (`re.fullmatch`, `ValueError`) and an author or committer that contains a line feed (`ValueError`).
